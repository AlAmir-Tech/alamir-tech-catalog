# الأمير تك | AL AMIR TECH — كتالوج المنتجات

واجهة أولية عربية RTL لكتالوج منتجات الأمير تك، مبنية بـ HTML وCSS وJavaScript لتناسب GitHub Pages.

## تشغيل محلي
افتح `index.html` في المتصفح.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى جذر المستودع.
2. افتح Settings → Pages.
3. اختر Deploy from a branch، ثم `main` و`/(root)`، واضغط Save.

## قبل الإطلاق العام
- استبدل علامة الحرف A المؤقتة بالشعار الرسمي داخل `assets/logo/` ثم حدّث `index.html`.
- أضف المنتجات الفعلية وصورها ومواصفاتها.
- لا تضف أسعار الجملة أو بيانات حساسة إلى مستودع Public.
- تحقق من رقم واتساب ورابطه الدولي، ومن سياسات الشحن والاستبدال والضمان.
- راجع كل الأسعار والكميات قبل النشر.

## ملاحظات
المنتجات الحالية فئات توضيحية وليست قائمة مخزون أو تأكيداً بتوفر المنتجات. لا توجد أسعار منشورة في هذه النسخة.
